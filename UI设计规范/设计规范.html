03 排版 TYPOGRAPHY

中文优先字体栈，11 级字号阶。基准 14px / 行高 1.5。字号阶刻意保留 0.5px 步进（13.5px），是密集型管理后台在信息密度与可读性之间的取舍结果。

✓ 应当
  • 正文用 --body，标题用 --ink，说明用 --muted
  • KPI 数值 28px/700/行高 1，配 12.5px 标签形成强对比
  • 表格单元格统一 13.5px，表头 12.5px/600
  • 脚注类文字行高放宽到 1.6，避免密集小字挤压
✗ 禁止
  • 用 --faint(#94A3B8, 2.6:1) 承载任何需要阅读的文字
  • 新增字号档位——11 级已覆盖全部场景，加档即失控
  • 正文使用 700 字重，强调用 600 或改颜色层级
  • 在深色侧栏用 #475569 做分组标题（2.4:1，已修正为 #94A3B8）

05 组件库 COMPONENTS

26 类组件，全部来自真实原型、非臆造。每块下方为可直接复制的 HTML 片段。

06 交互模式 PATTERNS

比组件更高一层的可复用资产——这五个模式是本项目原型真正的差异化价值，也是最值得其他项目借鉴的部分。

07 无障碍 ACCESSIBILITY · WCAG 2.1 AA

本节是对原型的诚实审计：原型在色彩对比上有 7 处不达标，UI Kit 已全部修正。移植到其他项目时请勿回退这些值。

✓ UI Kit 已内置
  • 统一 :focus-visible 焦点环（2px 主色 + 2px 偏移）——原型完全缺失
  • 7 个 --*-text 安全色变体，全部实测 ≥4.5:1
  • 侧栏分组标题提亮至 6.9:1
  • prefers-reduced-motion 降级
  • .sr-only 屏幕阅读器专用类
✗ 仍待补齐（移植时须做）
  • 模态/抽屉的焦点陷阱与 ESC 关闭、打开时焦点转移
  • 权限矩阵 ✓/◐/✗ 需配 aria-label——纯符号对读屏不可用
  • 状态不可仅靠颜色传达：冲突态需同时给红框+文案+图标
  • 触控目标 ≥44px（当前 .pill 仅 32px，触屏场景需放大）
  • 图表（雷达图/热力图）需提供等价数据表
