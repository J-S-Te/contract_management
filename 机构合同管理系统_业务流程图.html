合同生命周期状态流转（CON-002）

共 9 种状态，支持自动归档与审批变更
stateDiagram-v2 title 合同生命周期状态流转 [*] --> draft : 创建合同 draft --> pending : 提交审批 pending --> draft : 审批拒绝 pending --> approved : 审批全部通过 approved --> active : 自动生效 active --> in_progress : 开始执行 in_progress --> pending_pay : 提交付款申请 pending_pay --> completed : 付款完成 completed --> archived : 归档（需审批） active --> archived : 到期自动归档 in_progress --> archived : 到期自动归档 completed --> terminated : 终止（需审批） in_progress --> terminated : 终止（需审批） active --> terminated : 终止（需审批） note right of pending : 审批中状态 note right of archived : 只读状态 note right of terminated : 合同终止
说明：
• 自动归档：系统每日凌晨定时检查，结束日期已过且状态为 active/in_progress 的合同自动归档，并通知相关人员。
• 审批变更：归档（archived）、终止（terminated）需提交状态变更申请，管理员审批通过后执行。
• 数据权限：销售人员只能查看自己创建的合同；管理员可查看所有合同。

审批功能增强操作流程（APP-005）

加签、转交、退回、撤回、催办
flowchart LR A(["审批人打开审批详情页"]) --> B{"选择操作"} B -->|同意| C["提交下一节点 或 流程结束"] B -->|拒绝| D["退回申请人

填写转交原因"] B -->|退回至任意节点| G["选择历史节点
填写退回原因"] B -->|撤回| H["申请人撤回
状态→草稿"] E --> E1["加签人审批完成
流程继续"] F --> F1["转交后原审批人
不再参与"] G --> G1["目标节点重新审批
按原路径继续"] H --> H1["通知所有已审批人"] X(["申请人/管理员"]) --> I["点击催办"] I --> I1["向当前审批人
发送催办通知"] C --> End(["流程继续/结束"]) E1 --> End F1 --> End G1 --> End style A fill:#e3f2fd,stroke:#1565c0,color:#000 style B fill:#fff3e0,stroke:#e65100,color:#000 style D fill:#ffebee,stroke:#c62828,color:#000 style C fill:#e8f5e9,stroke:#2e7d32,color:#000 style I1 fill:#f3e5f5,stroke:#7b1fa2,color:#000
功能说明：
• 加签：将其他人员加入当前审批节点（会签/或签），完成后流程继续。
• 转交：将审批任务转交他人，原审批人不再参与，需填写转交原因。
• 退回至任意节点：可退回至已通过的任意历史节点，目标节点重新审批。
• 撤回：申请人可在审批完成前撤回，合同状态回退至「草稿」。
• 字段变化对比：审批表单自动高亮变更字段，支持展开「变更对比」面板。
• 催办：申请人或管理员可手动催办，系统也可按配置频率自动提醒。

合同文档安全验证流程（CON-004）

5 步安全验证，防止恶意文件上传
flowchart TD Up(["用户上传合同文档"]) --> S1["① 文件类型白名单验证"] S1 -->|扩展名不在白名单| RJ1["❌ 拒绝上传"] S1 -->|通过| S2["② 双重扩展名检测"] S2 -->|检测到双重扩展名| RJ2["❌ 拒绝上传"] S2 -->|通过| S3["③ 文件内容扫描
（读取前4KB）"] S3 -->|含恶意代码特征| RJ3["❌ 拒绝上传"] S3 -->|通过| S4["④ MIME类型校验"] S4 -->|MIME与扩展名不匹配| RJ4["❌ 拒绝上传"] S4 -->|通过| S5["⑤ 文件路径清理"] S5 -->|含路径遍历字符| RJ5["❌ 拒绝上传"] S5 -->|通过| OK["✅ 验证通过
保存文件至 uploads 目录"] OK --> TK["生成5分钟有效预览令牌"] TK --> PV["用户预览文档"] style Up fill:#e3f2fd,stroke:#1565c0,color:#000 style OK fill:#e8f5e9,stroke:#2e7d32,color:#000 style RJ1 fill:#ffebee,stroke:#c62828,color:#000 style RJ2 fill:#ffebee,stroke:#c62828,color:#000 style RJ3 fill:#ffebee,stroke:#c62828,color:#000 style RJ4 fill:#ffebee,stroke:#c62828,color:#000 style RJ5 fill:#ffebee,stroke:#c62828,color:#000 style TK fill:#fff3e0,stroke:#e65100,color:#000 style PV fill:#f3e5f5,stroke:#7b1fa2,color:#000
安全验证说明：
• 白名单：仅允许 .pdf / .docx / .jpg / .png / .txt / .csv 等安全扩展名。
• 双重扩展名：防止 malicious.php.jpg 绕过类型检查。
• 内容扫描：读取文件头 4KB，检测恶意代码特征（如 PHP Webshell 特征）。
• MIME 校验：防止将 .php 文件伪造为 image/jpeg 上传。
• 路径清理：防止路径遍历攻击（如 ../../../etc/passwd）。
• 预览令牌：文档预览需携带 5 分钟有效令牌（POST /api/documents/:id/preview-token）。

• 本模块仅提供查询展示功能，客户/供应商数据的增删改由外部系统维护。
